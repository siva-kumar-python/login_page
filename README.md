# 🔐 Login Page UI

A small front-end practice project: a polished **login screen** built from scratch with nothing but HTML and CSS.

## ✨ What's inside

- 🎨 Background image layout (`bg1.jpg`)
- 🔒 Lock icon + user icon design details (`lock.png`, `user.png`)
- 💅 Pure CSS styling — no frameworks, no libraries

## 🚀 Run It

Just open `login1.html` in any browser. That's it!

```bash
git clone https://github.com/siva-kumar-python/login_page.git
cd login_page
# open login1.html in your browser, or:
python -m http.server 8000
```
